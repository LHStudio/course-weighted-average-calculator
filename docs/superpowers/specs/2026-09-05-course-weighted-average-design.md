# 课程加权平均分计算系统设计说明

## 目标

构建一个无需安装额外依赖即可双击运行的 Windows 桌面工具，读取用户提供的 `.xls` 成绩表，按课程选择和去重规则计算每名学生的课程加权平均分，并导出与参考图片一致的 Excel 汇总表。

## 用户流程

1. 启动程序后自动查找程序目录或当前目录中的成绩文件，也可通过“打开成绩文件”选择 `.xls`、`.xlsx` 或 `.csv`。
2. 程序识别成绩字段，展示学生列表和当前学生的课程清单。
3. 用户选择去重依据：课程代码或课程名称；选择重复记录处理方式：最后一条、第一条或全部保留。
4. 用户在当前学生的课程清单前勾选需要纳入计算的课程，可全选、全不选，也可将当前选择应用到所有学生。
5. “文字成绩换算”窗口展示文件中出现的非数字成绩。未启用的文字成绩不参与计算，启用后按用户填写的等效分数参与计算，也支持新增文字状态。
6. 点击“计算”刷新预览，点击“导出 Excel”生成格式化的排名表。

## 计算规则

- 原始记录按文件顺序保留 `source_index`，用于“第一条/最后一条”去重。
- 去重分组键为 `(student_id, course_code)` 或 `(student_id, course_name)`，由界面快捷选项决定。
- 数字成绩支持整数和小数；文字成绩通过映射转换，未映射值为不可计算。
- 仅统计已选、学分有效且成绩可解析的课程。
- `总学分 = sum(学分)`。
- `总成绩 = sum(成绩)`。
- `平均成绩 = 总成绩 / 课程数`。
- `加权平均分 = sum(成绩 * 学分) / 总学分`。
- 默认 4.0 绩点分段为：90/4.0、85/3.7、82/3.3、78/3.0、75/2.7、72/2.3、68/2.0、64/1.5、60/1.0、0/0.0；最低分阈值和绩点可编辑。
- `学分绩点 = sum(绩点 * 学分)`。
- `平均学分绩点 = 学分绩点 / 总学分`。
- 排名按加权平均分降序，采用竞赛排名（同分同名次，中间名次跳过）；不可计算学生的结果和排名均为空。
- 导出学生顺序按输入文件首次出现顺序，排名列单独反映加权平均分名次。

## 模块边界

- `course_calculator.py`：数据模型、HTML 型 `.xls` 解析、去重、文字成绩解析、绩点换算和学生汇总计算；不依赖 Tkinter。
- `excel_io.py`：使用 openpyxl 读取常见 `.xlsx`，生成带样式的汇总 `.xlsx`。
- `app.py`：Tkinter/ttk 界面、状态管理、勾选交互、文件对话框和错误提示。
- `tests/`：计算核心、解析、导出结构和端到端样例测试。
- `build_exe.ps1`：使用 PyInstaller 构建单文件窗口程序，不携带控制台窗口。

## 界面结构

- 顶部工具栏：打开文件、去重依据、重复处理、文字成绩换算、绩点规则、计算、导出。
- 左侧学生列表：显示学号、姓名、当前是否可计算。
- 右侧课程选择区：每行前置复选框，显示课程代码、课程名称、学分、成绩、取得学期、课程类别；支持滚动、全选、全不选和应用到全部学生。
- 下方结果预览：显示十个导出字段，无法计算的数值显示为空。
- 底部状态栏：文件名、学生数、记录数和最近操作结果。

## 非功能要求

- 读取实例 `.xls` 时不要求安装 Excel 或 Office；该实例是 Excel HTML 表格，使用标准库 HTML 解析器读取。
- EXE 使用 PyInstaller one-file/windowed 模式，运行时不要求 Python、openpyxl 或其他依赖。
- 界面只在必要位置提示错误；导出文件中不写入解释性备注，无法计算的字段保持空白。
- 所有核心计算使用纯 Python，可在无图形环境下通过单元测试验证。

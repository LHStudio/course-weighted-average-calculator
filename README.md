# 课程加权平均分计算器

## 直接使用

双击项目根目录中的 `课程加权平均分计算器.exe`。程序可以读取：

- 当前实例这种由 WPS/Excel 导出的 HTML 型 `.xls`
- `.xlsx`
- `.csv` 和 `.tsv`

当前 EXE 与实例成绩表位于同一目录，启动后会自动读取 `2402成绩-25-26学年.xls`。也可以点击“打开成绩文件”选择其他文件。

## 主要操作

1. 在“去重依据”中选择“按课程代码”或“按课程名称”。
2. 在“重复记录”中选择“最后一条”“第一条”或“全部保留”。默认使用最后一条。
3. 从左侧选择学生，在右侧勾选需要计算的课程。
4. 使用“应用当前科目方案到全部学生”快速统一全班的科目范围。
5. 在“文字成绩换算”中启用“优秀”“合格”等成绩并填写等效分数；未启用时该条成绩不参与计算。
6. 在“绩点规则”中按需要修改分数段和绩点。
7. 点击“导出 Excel”，生成包含年级、学号、姓名、总学分、总成绩、平均成绩、加权平均分、学分绩点、平均学分绩点和排名的工作簿。

排名按加权平均分降序计算，同分使用相同名次。没有任何可计算课程的学生，其计算字段和排名保持为空。

## 从源码运行

```powershell
python app.py
```

## 重新打包

开发环境需要 Python、openpyxl 和 PyInstaller：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

打包后的 EXE 为单文件窗口程序，使用者不需要安装 Python 或其他依赖。
